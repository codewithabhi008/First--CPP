# First C++ 🚀

Welcome to **First--CPP** — a beginner-friendly C++ programming repository created to practice and understand the fundamentals of **C++ programming**.

This repository contains simple C++ programs covering basic programming concepts, variables, input/output, classes, objects, constructors, and more.

## 📚 Topics Covered

* C++ Basics
* Variables and Data Types
* Input and Output
* Printing Numbers
* Classes and Objects
* Constructors
* Encapsulation
* Getters and Setters
* Employee Class
* Student Class

## 📂 Programs

| File                 | Concept                       |
| -------------------- | ----------------------------- |
| `Basics.cpp`         | C++ Basic Concepts            |
| `Variable.cpp`       | Variables                     |
| `PrintingNumber.cpp` | Printing Numbers              |
| `Employee.cpp`       | Employee Class                |
| `Employee2.cpp`      | Employee Class & Constructors |
| `Studentclass.cpp`   | Student Class                 |

## 🛠️ Technologies Used

* **Language:** C++
* **Compiler:** GCC
* **IDE:** Visual Studio Code
* **Platform:** Windows

## ▶️ How to Run

### Clone the Repository

```bash
git clone https://github.com/codewithabhi008/First--CPP.git
```

### Open the Project

```bash
cd First--CPP
```

### Compile a C++ Program

```bash
g++ Basics.cpp -o Basics
```

### Run the Program

```bash
.\Basics.exe
```
